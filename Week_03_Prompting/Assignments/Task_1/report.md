1. FRAMEWORK RTF

I chose Role-Task-Format framework from the website https://frompting.com/frameworks, because specifying the role can help AI understand how it should behave and understand the responsibilities. The task is the main part which we have to include into prompt, so it also fits. The format section defines how the output CSV file should be structured. Therefore, RTF is a suitable framework for this task.

2. FRAMEWORK 

I also chose the Role-Action-Context-Expectation (RACE) framework from the website https://frompting.com/frameworks because it provides a clear structure for explaining the task. The role defines the AI's responsibilities, the action specifies the conversion of natural-language questions into SQL queries, and the context provides information about the database schema and input dataset. The expectation describes the desired result, including the correct output file and preservation of the original dataset structure. This framework makes the prompt more precise.

3. FRAMEWORK ICIO

I chose the Instruction-Context-Input-Output (ICIO) frameworkfrom the website https://frompting.com/frameworks because the task involves processing specific input files to generate a structured output file. The instruction explains what the AI must do, the context describes the database and the purpose of the task, the input identifies the provided CSV files, and the output defines the expected predictions file. This framework clearly separates the instructions from the input data and the expected result.
